# 豆皮的生活台 · 导入与运行指南

## 导入微信开发者工具（3 步）

1. 打开微信开发者工具（Nightly 版），主界面点「**导入项目**」（不是「创建小程序」——创建会生成空项目，浪费已有代码）
2. 目录选择本目录：`lifedesk-miniprogram`
   - 确认标准：AppID 栏自动带出，不报「未找到 project.config.json」
3. 后端服务选「**微信云开发**」，初始化选「**不使用云服务**」（云同步由代码内配置控制，见下）

## AppID 说明

- **有正式小程序号**：填真实 AppID → 云开发可用，多设备同步
- **没有**：点「注册或使用测试号」→ 可预览全部界面 + 本地存储功能；云同步自动降级为本地模式（不影响使用）

## 开启云同步（可选，需正式号）

1. 工具里点「云开发」按钮开通环境（登录页选「**微信公众平台登录**」，不要选腾讯云账号）
2. 云开发控制台 → 设置 → 环境信息，复制完整 EnvId（形如 `cloud1-xxxxxxxx`）
3. 小程序内进入「更多 → 备份与恢复 → CLOUD 配置」，粘贴 EnvId 保存，**完全关闭小程序再重进**即生效
4. 数据库集合 `lifedesk` 权限设置为「仅创建者可读写」（控制台 → 数据库 → lifedesk → 权限设置）

## 从「自己用」到「大家都能用」（上线路线）

多用户版需要：**正式小程序账号 + 云开发 + 两个云函数部署 + 数据库权限 + 提交审核**。测试号做不到（无法被他人访问、无法发布）。

### 第 1 步：注册正式小程序（个人主体免费）

1. mp.weixin.qq.com → 注册 → 小程序 → 个人主体
2. 邮箱激活 → 主体信息登记（身份证 + 微信实名）
3. 审核约 1-3 天，通过后获得 **AppID**
→ 确认标准：公众平台首页能看到你的小程序，设置里能看到 AppID

### 第 2 步：开发者工具切换 AppID

1. 导入本项目，详情 → 基本设置 → AppID 改为正式 AppID
2. 点「云开发」按钮开通环境
   - 登录页务必选「**微信公众平台登录**」，不要选腾讯云账号
   - 按量付费环境即可（个人免费用度够）
→ 确认标准：云开发控制台能打开，显示环境 ID（形如 cloud1-xxxxxxxx）

### 第 3 步：部署两个云函数

在开发者工具里，对 `cloud/functions/openid` 和 `cloud/functions/dingtalk-sync` 分别：
右键 →「上传并部署：云端安装依赖（不上传 node_modules）」
→ 确认标准：云函数列表出现 openid / dingtalk-sync 两个函数

### 第 4 步：建数据库集合 + 权限

1. 云开发控制台 → 数据库 → 新建集合 `lifedesk`
2. 集合 → 权限设置 → 选「**仅创建者可读写**」
   - 这条规则配合 openid 文档隔离：每人只能读写自己的数据
→ 确认标准：lifedesk 集合存在，权限显示「仅创建者可读写」

### 第 5 步：填入 EnvId，云同步生效

小程序内：更多 → 备份与恢复 → CLOUD 配置 → 粘贴 cloud1-xxxxxxxx → 保存 → **完全关闭小程序重进**
→ 确认标准：首屏右上角显示「云端同步」（不再是「本地模式」）

### 第 6 步：上传 → 提交审核 → 发布

1. 工具右上角「上传」（版本号如 1.0.0，备注写清楚）
2. mp.weixin.qq.com → 版本管理 → 开发版本设为体验版，自己先扫码验一遍
3. 提交审核：类目选「**工具 → 信息查询****
4. 审核通过后点「发布」——全微信用户可搜索使用
→ 确认标准：公众平台显示「已发布」，别人微信搜得到

### 审核注意事项（个人主体）

- 数据均为用户自用数据，无 UGC 公开展示，无支付，工具类目可过
- 首次审核约 1-2 天；如被拒，按驳回原因改后重新提交
- 「云开发」按量付费有免费额度，个人使用一般不会产生费用

## 数据说明

- 数据存 localStorage 等价物（`wb_lifedesk_data_v1`），输入即保存，关闭不丢
- 数据面板支持：JSON 导出/导入（不限条数）、恢复上次良好副本、清空
- 与 HTML 版生活工作台数据模型同源，可跨端导入 JSON
